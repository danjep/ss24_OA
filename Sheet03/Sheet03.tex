\section*{Exercise \printsheet.1: Online Bin Packing - Next Fit}
For the first $n+1$ bins we first give an item of size $\alpha$ and then give items such that there is only space $\alpha-\varepsilon$ left in the bin and Next Fit needs to continue with the next bin. After $n$ bins we give $n+1$ requests for items of size $\alpha-\varepsilon$. Next Fit will fill one bin to exactly $1$ before it fills each of the following bins with $\left\lfloor \frac{1}{\alpha-\epsilon} \right\rfloor$ items, therefore using  $\frac{n}{\left\lfloor\frac{1}{\alpha-\epsilon}\right\rfloor}$ bins. \\

Since we can make $n$ arbitrarily large, the one bin that is optimally filled can be ignored. \\
Overall, Next Fit needs to use at least $n+n\mal (\alpha-\epsilon)$ bins, while OPT only needs $n$ which leads to: 
\[\frac{c_{NF}}{c_{OPT}} \geq \frac{(n + n \mal (\alpha-\epsilon)}{n} = 1+ \alpha -\epsilon \] 

For $\alpha \leq \frac{1}{2}$ the offset $\epsilon$ can be very small which makes $\alpha - \epsilon$ almost as big as $\alpha$ and therefore
\[\frac{c_{NF}}{c_{OPT}} \geq 1 + \alpha \] %\frac{1}{\alpha}\]

For $\alpha > \frac{1}{2}$ the offset is such that $\alpha - \epsilon = 1-\alpha$. In this case: 
\[\frac{c_{NF}}{c_{OPT}} \geq 1+ 1-\alpha\]

\section*{Exercise \printsheet.2: Online Bin Covering}
\subsection*{(a)}
We use the Next Fit algorithm, but go to the next bin when the current one is covered. \\
In the worst case the algorithm gets $2n$ items with weight $1-\epsilon$ and after that $n+1$ items with weight $\epsilon$. The optimal algorithm would use $2n$ bins, while Next Fit would use two of the $1-\epsilon$-items to fill the first $n$ bins and then fill one bin with the last $n$ items which would be to small to cover it. Therefore Next Fit would cover $n$ bins.

\[\frac{c_{OPT}}{c_{NF}} = \frac{2n}{n} = 2\]

For any deterministic algorithm A that does not try to cover the bins immediately, the adversary can simply stop the requests whenever the algorithm wants to start filling up the opened bins. For Next Fit the competitive ratio was already determined, therefore there can't be any deterministic algorithm for Online Bin Covering that has a competitive ratio $c < 2$.

\subsection*{(b)}
For the asymptotic competitive ratio, algorithms that don't cover the bins immediately can be used since the input needs to be infinitely long.\\

Let A be an algorithm that allows $k \in \N$ opened bins at a time. The worst case would be to let A cover as many bins as possible with two items of size $1-\epsilon$ while OPT can cover all bins with items $1-\epsilon$ and $\epsilon$. \\

The adversary gives $(2\alpha + 1)k$ (with $\alpha \in \N_{\geq 1}$) many requests of size $1-\epsilon$ and just as many items of size $\epsilon$ to make it possible that OPT covers each bin with items adding up to $1$. We can't give the $\epsilon$-items earlier, since this would enable A to open bins with one $\epsilon$-item and cover it with an $1-\epsilon$-item. \\
Since A will always keep $k$ bins open, it will have covered $\alpha \mal k$ bins with two items of size $1-\epsilon$ before using the $\epsilon$-items. A can't cover a bin only with $\epsilon$-items. \\

This results in A covering $(\alpha + 1) k$ bins and OPT covering $(2\alpha + 1)k$ bins.
\[c = \frac{c_{OPT}}{c_A} = \frac{(2\alpha + 1)k}{(\alpha+1)k}= \frac{2\alpha + 1}{\alpha + 1} \overset{\alpha \geq 1}{\geq} \frac{3}{2} \] 


\section*{Exercise \printsheet.3: Online Graph Coloring}
Let A be any deterministic online algorithm for Graph Coloring. For any $k \in \N$ we construct a forest $T_k$ that forces A to use $k$ colors.\\
$T_1$ is just a single vertex that obviously needs to be colored in one color.
For $T_2$ we construct the Graph $T_1$ and connect it to a new vertex, forcing A to use a new color. \\

In the same manner we construct a forest $T_k$ for $k\in \N$ recursively. First we construct $T_i$ for all $i \in \{1,\dots, k-1\}$. Since in each $T_i$ there must be at least one more color than in $T_{i-1}$, A already used $k-1$ colors. Now we introduce a new vertex that is connected to each $T_i$ via the vertex that uses a color that is not used in $T_{i-1}$. Since that new vertex has neighbours with all the $k-1$ colors already used by A, the algorithm needs to use a new color. \\

Since each $T_i$ is a forest and these are connected through a single vertex, there is only one unique path from each $T_i$ to another, making $T_k$ a forest too.
